# Security Policy

## Vulnerability Reporting
To report a security vulnerability or sensitive finding, please open a private security advisory on the GitHub repository or contact the maintainer directly via GitHub rather than filing a public issue.

## Data Processing & Scope Policy
Per hackathon guidelines and project boundaries, AegisRAG strictly processes publicly available, non-personal web data (e.g., public GitHub repository feeds and open software metrics) and enforces a pre-embedding PII redaction filter to eliminate accidentally ingested personal identifiers.
